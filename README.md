# Websites

Websites I build for local businesses in Dartford and North Kent. Each site lives in its own folder.

| Site | What it is |
|------|------------|
| [Dartford Spark Electrical](dartford-spark/) | Demo site for a made-up electrician. Quote form that emails me (Formspree), dark/light mode, text size settings, works on phones. |
| [Copperline Plumbing & Heating](copperline-plumbing/) | Demo site for a made-up plumber in Gravesend. Price list, next free slot card, FAQ. |
| [Ridgeway Roofing](ridgeway-roofing/) | Demo site for a made-up roofer in Swanley. Free drone survey offer, how-it-works steps. |
| [Bramble Hair Studio](bramble-hair/) | Demo site for a made-up hair salon in Wilmington. Price menu, live opening hours, booking request form. |
| [Kestrel Autocare](kestrel-autocare/) | Demo site for a made-up garage in Crayford. MOT and repair prices, number-plate booking form. |

## Live
Hosted free on GitHub Pages: `https://noisyboy2905.github.io/websites/`

## Adding a new site
1. Make a new folder, e.g. `gravesend-plumbing/`, with its own `index.html`, `style.css`, `script.js` and `images/`.
2. Add a card for it on the front page (`index.html`) and a row in the table above.
3. Commit and push. It goes live at `https://noisyboy2905.github.io/websites/<folder-name>/`.

Built with plain HTML, CSS and JavaScript. No frameworks.
